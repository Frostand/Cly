# Screenshot review checklist

Score each issue P0 broken, P1 major, P2 polish, or P3 optional.

- Horizontal overflow, clipped controls, overlap, detached pseudo-elements
- Pane minimum sizes, useful collapse behavior, visible resize handle
- Table header alignment, density, sorting visibility, long-cell handling
- Graph fit, readable nodes/edges, isolated keyboard behavior
- Empty inspectors, redundant panels, nested borders, card-wall layout
- Purple overuse, icon inconsistency, weak focus, low contrast
- Verbose subtitles, duplicate status, long buttons, unclear empty states
- Composer and terminal scrolling, reduced motion, narrow-window behavior

Record: route, viewport, severity, evidence path, intended fix, verified result.
