# Cly UI copy

1. Identify the user's decision or action on the screen.
2. Remove subtitles that repeat the title or visible structure.
3. Prefer noun labels and verb-first buttons under four words.
4. State empty conditions plainly, then offer one next action.
5. Use one status phrase per object; do not repeat it in badge, subtitle, and body.
6. Preserve evidence, uncertainty, warnings, approval details, scientific constraints, paths, hashes, and provenance.
7. Review examples in `references/examples.md` before large copy sweeps.

Avoid generic phrases such as “manage all your…”, “seamlessly”, “powerful”, and “get started.” Do not shorten safety or reproducibility findings merely for visual neatness.
