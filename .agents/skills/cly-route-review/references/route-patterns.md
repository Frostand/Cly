# Cly route patterns

| Route | Primary pattern | Toolkit |
|---|---|---|
| Overview | project summary + timeline + key actions | continuous sections |
| Agent Sessions Overview | compact session list | virtual list for 100+ |
| Agent Sessions Chat | chat + tabbed workbench | `ClySplitPane`, xterm, Radix mode controls |
| Context | category/item workspace + preview/budget | nested `ClySplitPane`, virtual list |
| Research Graph | relationship canvas + inspector | React Flow |
| Experiments | sortable table + run detail | `ClyDataTable`, split detail |
| Sources | sortable list/table + preview | `ClyDataTable`, split preview |
| Literature | comparison matrix | TanStack table/virtual, column controls |
| Notebooks | notebook outline/list + detail | virtual list, disclosure, split detail |
| Code Linker | code outline + research detail | virtual tree, split detail |
| Claims | table by default; compact board when useful | TanStack table, evidence inspector |
| Provenance | artifact list + lineage | table/list, React Flow only for lineage |
| Reproducibility | audit report + finding list | virtual findings, disclosure, progress |
| Decisions | chronological timeline | virtual long history |
| Next Steps | prioritized list/roadmap | TanStack virtual, detail inspector |
| Integrations | grouped rows/catalog | accessible dialogs, no card wall |
| Models & Agents | provider/model table + configuration | table, split configuration |
| Settings | native preference rows | concise groups and controls |
