# Repo-local Codex UI skills

Skills live under `.agents/skills/`:

- `cly-design-system`: tokens, hierarchy, approved components, anti-patterns
- `cly-visual-polish`: Electron screenshot loop and capture/index scripts
- `cly-ui-copy`: concise interface-copy rules with Cly examples
- `cly-accessibility-review`: keyboard/ARIA/axe workflow
- `cly-route-review`: route-to-layout decision map

Each skill includes generated `agents/openai.yaml` metadata and is validated with the Codex skill validator. Invoke explicitly as `$cly-design-system`, for example.
