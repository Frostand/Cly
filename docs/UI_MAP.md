# UI Map

| Destination | Primary views | Important actions |
|---|---|---|
| Overview | status strip, question/hypothesis, activity, claims, next action, graph preview, reports | open graph, inspect risk, review next action |
| Agent Sessions | Overview; task identity; conversation; plan/progress; approvals; context; agent-only, inline, detached-intent, and external-editor-intent modes; optional workbench | start task, send direction, inspect tests/diff, approve/reject, switch project/session, detach/reattach prototype, resume |
| Context | composer, exact agent preview, context packs, budget | include, exclude, pin, summarize/raw, reorder, save |
| Research Graph | graph, outline, relationships, evidence chain | search, filter, zoom, trace, create/approve link |
| Experiments | experiment list, runs, compare, timeline, outputs | create, compare, duplicate boundary, report |
| Sources | searchable table and inspector | import, BibTeX, URL, bundle, link, metadata, archive |
| Literature | matrix, themes, chronology, claims, methods, NotebookLM | edit matrix, outline, gap analysis, export/import companion workflow |
| Notebooks | list and static cell outline | import, scan, summarize, extract, mark canonical, audit |
| Code Linker | files, objectives, claims, risks, unlinked | approve purpose, link object, trace output, request review |
| Claims | board, table, detail and evidence chain | create, status, link evidence, contradiction, review, report |
| Provenance | gallery, table, lineage, broken/stale/unlinked | trace, compare, mark, report |
| Reproducibility | score, findings, coverage | run/compare audit, resolve/assign, checklist, publication package |
| Decisions | timeline, active, superseded, unresolved, linked | create, evidence, branch, compare, export |
| Next Steps | priority queue, roadmap, claim/experiment/risk/effort | accept, defer, dismiss, convert to session |
| Integrations | catalog, connection modes, routing | manage/setup fixture state, choose routing/privacy |
| Models & Agents | presets, topology, advanced controls | add/remove/duplicate/reorder role, save, preview |
| Settings | appearance, behavior, privacy, defaults, shortcuts, fixtures, diagnostics | update local UI preferences |
