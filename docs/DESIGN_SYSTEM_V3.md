# Design System V3

V3 keeps the continuous desktop workspace introduced in V2 and adds professional interaction/data primitives.

- 4/8/12/16/24px spacing scale
- 28px controls, 36px rows, 38px table rows
- workspace → surface → raised surface hierarchy
- purple reserved for focus, selection, progress, and primary action
- 5px keyboard-accessible split handles
- sticky sortable table headers and keyboard-selectable rows
- xterm for terminal content; React Flow for genuine relationships
- 120ms control and 180ms panel motion, disabled under reduced motion
- Lucide outline icons: 14px standard, 16px navigation, 22–28px empty states

Avoid card walls, decorative pills, unexplained empty inspectors, duplicate subtitles, and global graph/editor key handlers.
