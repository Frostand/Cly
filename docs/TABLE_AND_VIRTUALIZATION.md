# Tables and virtualization

`ClyDataTable` uses TanStack Table for sorting, filtering state, saved column visibility, stable row IDs, and keyboard selection. Use it when users compare records across columns.

`ClyVirtualList` uses TanStack Virtual with eight-row overscan. Use it for long scan-oriented lists and provide a stable key plus realistic row estimate.

Current integrations: Sources, Experiments, Runs, and large Next Steps. Large fixtures remain deterministic. Keep table headers sticky and never truncate the only copy of scientific evidence without a detail view.
