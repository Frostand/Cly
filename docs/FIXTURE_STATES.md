# Fixture States

The development-only fixture selector is available in the title bar and Settings.

| State | Purpose |
|---|---|
| Empty | All research collections empty; validates first-run states. |
| New Project | One source and project direction; validates early onboarding. |
| Active Project | Default coherent, linked research dataset. |
| Large Project | 1,000 sources, 500 claims, 500 experiments, 1,000 runs, 100 notebooks, 2,000 graph nodes, 5,000 edges, 500 artifacts, 500 decisions. |
| Loading | Shared service-hydration loading state for every destination. |
| Integrity Risks | Weak claims, low audit score, and elevated findings. |
| Offline | Local objects available; network integrations unavailable. |
| Integration Errors | Permission, sync, and partial-data failures. |

Active fixtures also include stale context, a stale notebook, manual artifact risk, failed runs, partial reproducibility, permission-required integration, planned integration, and unresolved decisions.
