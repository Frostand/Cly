# Cly product background

Cly is a local-first research platform for computational and code-assisted research. It gives a project one evidence trail:

```text
question → sources → methods → external code/notebooks → experiments
         → outputs → claims → decisions → reports
```

It is a companion to existing research tools, not an integrated coding workspace. Cly tracks research state, provenance, and approval-gated agent work while researchers continue to code and execute in their preferred environments.

The product is intended for researchers, students, research engineers, independent scientists, and teams working in computational disciplines.
