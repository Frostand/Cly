# Storybook


The accessibility addon treats violations as errors. Initial stories cover persisted split panes, Radix dialogs, xterm fixtures, feedback states, and tooltips in the real dark theme. Add route-neutral shared components here; keep complete route workflows in Electron E2E.
