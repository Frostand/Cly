# Agent Sessions Overview Mode

Overview is the management and monitoring surface.

It provides:

- compact Running, Waiting approval, Completed, and Saved presets counts;
- Active, History, and Approvals filters;
- persisted sorting and session selection;
- search across title, objective, preset, Orchestrator, and related research objects;
- structured session rows with objective, status, progress, Orchestrator, delegated-agent count, model/reasoning, context, branch/worktree, elapsed time, outputs, related objects, approvals, and risk;
- explicit Open chat, pause/resume, archive, and configure-team actions;
- a meaningful selected-session inspector that collapses at narrow desktop widths.

Returning from Chat never stops work. Session mutations remain in the shared store and immediately appear in Overview.
