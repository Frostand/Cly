# Visualization patterns

Use the smallest visual that answers the question.

- Trend over ordered observations → `Sparkline`; include all values in the accessible name.
- Research phase → `ResearchLifecycle`; one current step, completed/future states remain textual.
- Context capacity → `TokenBudgetBar`; segments are actual included-item categories.
- Claim assessment → `EvidenceStrength`; confidence is displayed alongside support and contradiction counts and is not presented as objective truth.
- Notebook structure → `ExecutionStrip`; cell kinds retain an accessible count summary.
- Audit priority → `RiskDistribution`; the finding list remains the actionable source of truth.
- Explicit research relationship → `RelationshipChain`; never infer missing lineage for decoration.
- Multi-object topology → React Flow; animate only a current handoff or selected trace.

Avoid fake research plots, decorative gauges, replaying charts, and collections of unrelated dashboard visuals.
