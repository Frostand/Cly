# Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| Cmd/Ctrl K | Command palette |
| Cmd/Ctrl O | Open project from native menu |
| Cmd/Ctrl Shift O | Project switcher |
| Cmd/Ctrl N | New claim from native menu |
| Cmd/Ctrl 1 | Overview |
| Cmd/Ctrl 2 | Agent Sessions |
| Cmd/Ctrl 3 | Context |
| Cmd/Ctrl 4 | Research Graph |
| Cmd/Ctrl 5 | Experiments |
| Cmd/Ctrl 6 | Claims |
| Cmd/Ctrl , | Settings |
| Cmd/Ctrl Option/Alt I | Toggle inspector |
| Cmd/Ctrl J | Toggle Activity drawer |
| Cmd/Ctrl \ | Toggle sidebar |
| Cmd/Ctrl F | Focus current search/filter |
| Escape | Close transient UI or clear selection |

Application-menu accelerators and renderer shortcuts use the same commands. Text inputs retain native editing shortcuts.
