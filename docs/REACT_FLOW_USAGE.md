# React Flow usage

React Flow is approved for Research Graph, meaningful provenance lineage, and agent topology. It is not a replacement for forms, timelines, or simple workflows.

The Research Graph uses custom Cly nodes, Cly-styled edges, pan/zoom, fit view, optional minimap, search/type/confidence filters, and store-backed selection. Keyboard behavior stays within the focused canvas.

The large fixture currently filters to 60 nodes and 120 edges. A production 2,000-node/5,000-edge view should add semantic clustering and level-of-detail rendering rather than drawing every label simultaneously.
