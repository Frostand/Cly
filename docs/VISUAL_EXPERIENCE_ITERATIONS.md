# Visual experience iterations

All passes used the real Electron application at 1024×700, 1280×800, 1440×900, and 1728×1117.

## Baseline

`artifacts/ui-review/motion-before/` captured 88 route and interaction screenshots. The app had good layout foundations but relied on isolated metrics, helper prose, and metadata lists for research state.

## Iteration 1: structure and meaning

`artifacts/ui-review/motion-iteration-1/` added the research lifecycle, data-derived sparklines, category token budget, claim evidence balance, notebook execution strip, code relationship chain, reproducibility risk distribution, and route/mode transitions. Review found filled sparkline areas and duplicated claim confidence.

## Iteration 2: density and comparison

`artifacts/ui-review/motion-iteration-2/` corrected sparkline geometry, reduced claim duplication, added impact/effort positioning, and consolidated provenance onto the shared relationship pattern. Narrow layouts retained the primary workspace with no root overflow.

## Iteration 3: restraint and consistency

`artifacts/ui-review/motion-iteration-3/` added source-type recognition, removed continuously animated agent topology edges, refined responsive presentation, and verified all route/interaction captures. The final automated review records zero horizontal overflow and no console/page errors.

Animations intentionally rejected: ambient gradients, floating cards, pulsing rows, replaying charts, continuous agent-routing lines, decorative graph motion, and movement on every hover.
