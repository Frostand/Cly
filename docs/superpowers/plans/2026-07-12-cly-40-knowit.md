# CLY-40 KnowIT Literature Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a native Cly desktop literature workflow based on KnowIT's useful search, ranking, source, and matrix concepts.

**Architecture:** Literature contracts and deterministic ranking live in the Cly research domain. Renderer actions use typed services; persisted sources flow through project-scoped Electron research routes into SQLite and provenance events. The copied FastAPI/Next.js code remains migration reference only.

**Tech Stack:** TypeScript, React, Electron, Hono, SQLite, Zod, Vitest.

## Global Constraints

- No KnowIT FastAPI or Next.js runtime dependency.
- Every persisted mutation is scoped to the active Cly project.
- CI uses deterministic fixtures and no paid APIs.
- Ranking explanations and provenance remain inspectable.
- The pre-existing `electron/local-service-smoke.test.ts` timeout is tracked separately from CLY-40 verification.
